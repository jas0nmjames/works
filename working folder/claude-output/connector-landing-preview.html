01

How to add it

One-time setup. Works on Pro, Max, Team, Enterprise, and Free (1-connector limit).
1
Open Claude Settings
Profile icon → Settings → Connectors
2
Add custom connector
Scroll to bottom of the Connectors panel.
3
Paste the URL
Use the MCP URL above. Name it "Jason's Portfolio."
4
Toggle on in chat
Click the + in any chat → Connectors → enable.
02

What it knows

Four tools. Claude picks the right one for your question.
search_projects get_project_details analyze_role_fit get_bio_context

Instead of loading my entire portfolio on every ask, Claude scopes each query. search_projects returns lightweight matches; get_project_details only pulls a full case study when Claude decides it's needed. analyze_role_fit takes a job description and returns the themes I should be pivoted on. get_bio_context surfaces targeted background — construction, AI, teaching — rather than a full bio dump.
